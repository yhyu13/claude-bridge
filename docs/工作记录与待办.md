### 第二轮：模型切换

- `setModel()` / `modelInfo()` / `spawnArgs()`（含 `--resume`）/ `pendingResume`
- `/api/model` GET+POST，切换广播 `model` 事件
- 手机面板分「切换模型」（对话不丢）/「切换后端」（对话清空）两段
- 实测可用：`null`/`opus`/`sonnet`/`fable`；被拒：`claude-opus-5-5`/`minimax-m3`/`haiku` 等

**修的两个真 bug**：
1. 模型行被 `pumpOnce()` 每秒用旧快照盖回 → 一个 DOM 状态只能有一个写入者
2. 桥接重启后手机永远停在旧值 → 推送型状态必须有"重连后重新拉"的路径（`resync()`）

**验证方式**：不刷新页面，杀桥接改启动模型再起，芯片自己变了。

## 四、Git 仓库管理（回应你的第 1 点）

**`claude-bridge` 本来就是 Git 仓库**，不需要初始化：

- 13 个提交，已连 `github.com:yhyu13/claude-bridge`（SSH remote）
- 58 个追踪文件，工作区干净，与 `origin/main` 同步
- `core.hooksPath=.githooks`，提交时自动跑 `scan-secrets` + `verify:quick`

**`C:\Git-repo-AI` 根目录不是 Git 仓库，我也没有把它 init。**
原因：根下有 **30 个互不相关的项目**（游戏、投资、Harness、渲染、个人工具…）。
在根上建仓库会把它们全部扫进来，包括 `node_modules` 和大量与本项目无关的私人数据。
这条已写成 TD 的 ADR-012。

如果你确实想要一个"总仓库"，正确做法是逐个子目录决定纳入哪些 + 写一份排除
`node_modules/`、`.env`、数据集、构建产物的 `.gitignore`。这是另一个工作量的事，
说一声我就做。
