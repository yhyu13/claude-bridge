## 第一部分：技术决策记录（ADR）

格式同 Martin Fowler 的 ADR。每条都必须写"代价"——没有代价的决策通常是没想到代价。

### ADR-001 模型切换 = 杀进程 + `--resume` 重开

**决定**：切模型时 `claude-session.js` 杀掉子进程，带 `--resume <sessionId>` 重开。

**为什么**：`--model` 是**启动参数**，活着的进程改不了。这是 CLI 的事实约束，不是设计选择。

**代价**：切换期间对话会短暂中断；必须记住 sessionId；`start()` 里
`lastCumulativeCost = 0` 必须保留（`--resume` 后 `total_cost_usd` 从 0 重数），
忘了会让成本显示跳变。

**推论**：切换**后端**不给 `--resume`——换谁计费不该把上下文带过去。

---

### ADR-002 后端切换 = 杀进程 + **不**带 `--resume`

**决定**：`setBackend()` 同样重开进程，但不给 `--resume`。

**为什么**：模型是"同一段对话换个大脑"，后端是"换一家供应商"——把对话带过去等于
把上一家的上下文和这一家的计费混在一起。

**代价**：切后端会丢对话。面板里两段之间用实线分隔并各带一句警告，就是为了让人在点之前
看懂这个区别。

---

### ADR-003 传输用轮询，SSE 只作备用

**决定**：主传输是 800ms 轮询 + `?since=` 游标；`/api/events` 保留 SSE。

**为什么**：**vivo 浏览器 EventSource 连上了但不投递数据帧**（实测）。为一家主力设备的
浏览器放弃实时性不划算。

**代价**：最坏 800ms 延迟（人眼不可察觉）；轮询请求数是 SSE 的常数倍量级。

**保质期**：这条基于 2026-10-10 的 vivo 浏览器实测。换手机或换浏览器版本时应重新验证。

---

### ADR-004 模型列表用别名，不用全名

**决定**：`config.json` 里写 `opus` / `sonnet` / `fable`，由 `setModel()` 映射到
`claude-opus-4-8[1M]` 之类。

**为什么**：中转网关会改名。写死全名等于把配置焊死在网关当前的命名上。

**代价**：多一层映射表。实测可用的别名：`opus`、`sonnet`、`fable`、`null`（CLI 默认）。

---

### ADR-005 脱敏与扫描从 `.scrub-denylist.json` 读，不硬编码

**决定**：`tools/scrub-fixture.js` 和 `tools/scan-secrets.js` 共用 gitignore 的
`.scrub-denylist.json`。

**为什么**：把本机身份串写进工具源码，工具本身就变成了泄露源——脱敏器和扫描器本身要能进仓库。

**代价**：多一个需要维护的配置文件（它不进版本库，需要 `cp .scrub-denylist.example.json`）。

---

### ADR-006 fixture 的 MCP 名用 `mcp__demo__` 保留前缀

**决定**：测试/fixture 里的第三方 MCP 工具名一律以 `mcp__demo__` 开头。

**为什么**：`scan-secrets.js` 的规则是 `mcp__(?!demo__)`，`demo` 是它**给 fixture 预留的
豁免槽**。误报的正确处理是改 fixture，不是削弱规则——那道闸是对的，它在
`aa74797` 那次泄露里确实抓到过东西。

**代价**：fixture 的工具名和真名不完全一样，长度得自己补足才能复现真实场景。

---

### ADR-007 视觉方向 = B+ 野兽派信号层（不是最好看，是最不像别人）

**决定**：采用 B+。

**为什么**：这是差异化选择，不是审美选择。调研时的排序理由（原生语言、无障碍最稳、
信息密度最高）**恰好都是"和别人一样"的三条**。产品能被记住的理由是"没人在代码里用过这个"。

**代价**：野兽派的默认观感是"吵"。B+ 的解法是**只有顶栏、危险命令、整轮失败三处能用 W3**，
其余一律压低。一旦有人给第五个元素加 W3，这个设计就失效了。

**保质期**：这是审美决策，调研样本有限。真机连读十分钟是否累**只有用户能验**，见待办 T-09。

---

### ADR-008 工具卡折叠态只显示耗时，不显示输出字节数

**决定**：折叠行是 `▌ READ  src\...  [73ms]  ✗  ＋`，字节数留在展开后的 body。

**为什么**：实测在 320px 上 ` · 12.4KB` 要多占 38px，而这 38px 正好是长 MCP 工具名时
路径列被压成 0 宽的原因。`DESIGN.md` §5 要求的是**耗时**，字节数是我们自己加的——
所以字节数让位。

**代价**：想知道输出多大得展开一次。

---

### ADR-009 工具名用 `max-width` 硬闸，**不**用 flex-shrink

**决定**：`.tool .name { flex: 0 0 auto; max-width: 38% }`，`.desc` 是唯一可收缩项。

**为什么**：三版实测对照——

| 写法 | 短名 `Bash` | 长 MCP 名 | 路径列 |
|---|---|---|---|
| `flex:0 0 auto` 不截断 | 正常 | 402px | **0px（内容消失）** |
| `flex:0 1 auto` + 省略号 | **15px（被饿死）** | 正常 | 正常 |
| `flex:0 0 auto` + `max-width:38%` | 正常 | 100.8px | 54.5px ✓ |

flex 溢出时收缩按「收缩权重 × 基准宽」分摊，`.desc` 的基准宽是整条路径，`.name` 只有
几个字母，所以短名会先被压没。`max-width` 才是正确的闸。

**代价**：长工具名最多占 38% 宽度，38% 以右被省略号代替。

**附带**：`overflow:hidden` 会把溢出**裁掉**，所以页面级横向溢出恒为 0px，抓不到这个 bug。
窄屏断言必须落在**内容宽度**上，不能落在容器溢出上。

---

### ADR-010 工具耗时由服务端测量，不在客户端掐表

**决定**：`claude-session.js` 按 `tool_use_id` 记开始时间，`tool_result` 时算差值，
经 `bridge.js` → `translator.js` 送上线。

**为什么**：`DESIGN.md` §5 要求工具卡显示耗时，而 **CLI 协议里根本没有这个字段**——
这是一直存在的功能缺口。客户端掐表会被 800ms 轮询的抖动污染。

**代价**：多一个跨三层的字段；`--resume` 重放的结果没有配对的 `tool_use`，
报 `null` 而不是 `0`——真的 0ms 和"从没计时"是两件事，混为一谈是在撒谎。

---

### ADR-011 `ready` 类状态必须有一条"重连后重新拉"的路径

**决定**：`resync()` 在三个时机调：首次连接、某次轮询失败后第一次成功、每次 `ready` 事件。
它现在拉三个端点：`/api/model`、`/api/backend`、`/api/status`。

**为什么**：模型和后端只在**切换时**推事件，`ready` 每个进程**只在 spawn 时**发一次。
桥接一重启，之后打开的页面收不到任何替代事件，状态会**自信地一直说错话**。

**代价**：多三个 fetch。`connect()` 开头那句 `if (polling) return;` 让"首次连接拉一次"
只发生一次，所以抽成 `resync()` 是必须的，不是整理代码。

**附带一条边界**：缺席不等于零。`/api/status` 的 ready 快照只带 `toolCount`，
把它当"技能数 0"报出去过一次。

---

### ADR-012 不在 `C:\Git-repo-AI` 根目录建 Git 仓库

**决定**：只有 `claude-bridge/` 是仓库。

**为什么**：根目录下有 30 个互不相关的项目（游戏、投资、Harness、渲染…）。
在根上 `git init` 会把它们全部扫进来——包括 `node_modules` 和与本项目无关的私人数据。

**如果用户坚持**：需要先逐个子目录决定纳入哪些，并写一份 `.gitignore` 排除
`node_modules/`、`.env`、数据集、构建产物。这是另一个项目的工作量，不是顺手能做的。
