全部的设计系统

border: 3px solid #000;
box-shadow: 4px 4px 0 #000;   /* blur = 0，承重 */
border-radius: 0;
· 按下时 translate(4px,4px) + 阴影缩到 0，像按进纸里。
· 阴影方向永远右下——光源在左上，这是人读物体的自然方向。
· 8px 间距刻度。重边框会累加认知负荷，得靠节奏把它撑开。
· 大写标题不是风格选择，是结构：小写字母有升降部，大字排在一起会碎。

配色（颜色 = 语义，不是装饰）

· 黄=主操作 / 青=技术信息 / 粉=告警 / 绿=成功 / 红=危险 / 紫=后端状态。
· 对比度是顺手的好处：#111 on #fdfbf7 = 18.1:1，WCAG AAA。

为什么这个产品值得考虑它

工具卡片里跑的是 rm -rf / git push --force。DESIGN.md §6.2 要求「危险命令高亮」。3px 黑边 + 整卡换红，是余光能扫到的告警形态，不用点开才发现。

代价

它是营销页的语言，被搬进产品界面会打架。密集信息面板套重边框会累加认知负荷—— 调研里的原话是「大多数采用发生在落地页、专题页，而不是密集数据面板」。 5 张工具卡往下滚，眼睛会很累。
