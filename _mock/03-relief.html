方案 C · 浮雕

对「新拟物」的修正版，不是照抄 · 暗色底

新拟物为什么失败

控件和背景同色，只靠柔和阴影定义边界。

→ 一个主动作按钮和它背后的背景长得一模一样，可读性归零。
→ 调研里的结论：neumorphism broke a core usability rule，而玻璃至少还留着一条可见边界。

这一版补回来的三样

/* 修正 1 · 描边兜底：边界不再只由阴影承担 */
border: 1px solid rgba(255,255,255,.085);

/* 修正 2 · 明暗阶差：凸起面比底亮一档，凹陷面比底暗一档 */
--bg:  #23242b   /* 底 */
--bg-2:#292b33   /* 凸起：亮一档 */
--bg-3:#1d1e24   /* 凹陷：暗一档 */

/* 单一光源固定左上，所有凸起阴影方向一致 */
--raise: -6px -6px 14px rgba(255,255,255,.055),
          6px  6px 16px rgba(0,0,0,.55);
· 修正 3：正文用高对比白，不用拟物配色里那种同色系浅灰。
· 按下按钮时 真的凹进去（阴影换成 inset）——这才是浮雕该有的反馈。
· 层级用明暗阶差表达：顶栏凸起 / 工作目录凹陷 / 助手正文凹陷。
这套修完之后，浮雕的「实体感」保住了，可读性也没塌。 但它仍然是暗色专属——层次全靠阴影堆出来，白天户外基本没法用。

适合什么时候

· 夜间模式。暗底 + 暖色强调，是这一套唯一能长时间看的前提。
· 单手盲操。凸起/凹陷的物理暗示，比边框线更容易在不看的情况下分辨。
