claude-bridge · 手机端前端 5 个方向

5 个 demo 用完全一样的内容——同一段 2026-10-10 的真实调试（模型切换 + close 竞态）， 同一个工作目录、同一个模型、同一批工具卡片。并排看才有意义。

plan 与完整设计规则 → _mock/PLAN.md ｜ demo 均为零依赖单文件，双击即开 ｜ 它们没有动 web/ 的任何一行

为什么是这 5 个：你要的三个（浮雕 / 新野兽派 / 透明玻璃）都在，另加两个—— 终端控制台是这个产品真正的原生语言，可信轨迹是我认为它最该有但现在没有的东西。
动手前先记住一条约束：DESIGN.md §5 是功能规格，列的东西一个都不能丢 （顶栏 / 消息流 / 工具卡片 / 成本条 / 输入区 / 中止 + 紧急停止 / 危险命令高亮）。 §5 末尾「不做代码高亮」是 MVP 边界，不是审美偏好——要动它是功能决定，得单独讨论。

液态玻璃

Apple iOS 26 Liquid Glass。最好看，但正文必须实底。
承重 blur+saturate · 8%白底 · 1px描边
代价 Apple 自己因可读性把透明度降了
适合 顶栏 / 输入框 / 面板这类 chrome
单独打开 ↗
B

新野兽派

Gumroad / Feastables / Linear。3px 黑边 + 零模糊硬阴影。
承重 box-shadow blur=0，按下压进纸里
优势 危险命令余光就能扫到
代价 它本是营销页语言，密集面板会打架
单独打开 ↗
C

浮雕

新拟物 2.0 —— 这是修正版，因为原版对比度归零。
修正 描边兜底 + 明暗阶差 + 高对比文字
优势 盲操时凸起/凹陷比边框线好认
代价 暗色专属，白天户外基本没法用
单独打开 ↗
D

终端控制台

我推荐
Claude Code 自身 / Warp。#000000 OLED 黑 + 等宽字。
承重 输出本来就是等宽的，别再翻译一遍
优势 对比度天花板，无障碍最稳，信息密度最高
代价 可读性用密度换，中文长时间读会累
单独打开 ↗
E

可信轨迹

2026 agentic UI。危险命令执行前先拦一次。
论点 气泡渲染「它说了什么」，这个渲染「它做了什么」
优势 唯一把执行前拦截做进视觉语言的
代价 唯一需要改后端的一个
单独打开 ↗
选型建议（我的排序，按「这个产品真正要解决什么」，不是按好看）： D 终端控制台 > E 可信轨迹 > A 液态玻璃 > C 浮雕 > B 新野兽派。

最省事的组合：D 的骨架 + E 的拦截闸 + A 的顶栏材质。 如果只挑一个，我选 D。
